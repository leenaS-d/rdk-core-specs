Core RDK Video (RDK-V) defines the common platform foundation for RDK-based video solutions through governed capabilities, standardized interfaces, lifecycle policies, and conformance requirements. It enables ecosystem-wide interoperability and portability while preserving flexibility for innovation and differentiation.

## RDK9 Release Overview

RDK9 is under active development, with the release being prepared to build on the Core RDK platform. Its specifications and interfaces are evolving toward an upcoming release for broader ecosystem adoption.

## Explore the RDK9 platform

Explore the RDK9 core and non-core components alongside standardized interfaces connecting applications, middleware, and vendor-layer implementations.

### Components Catalog

Explore the RDK9 Components Catalog, connecting application-facing capabilities with middleware and vendor-layer implementations.

### Northbound APIs

Application-facing interfaces that give web and native apps consistent access to platform capabilities.

### Southbound APIs

Hardware abstraction interfaces that connect middleware with vendor implementations and platform hardware.
